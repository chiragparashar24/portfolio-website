# 🚀 GitHub Pages Deployment - Quick Commands

## One-Command Deploy ⭐

```bash
npm run deploy
```

That's it! Your portfolio goes live on GitHub Pages.

## Step-by-Step Deploy

```bash
# 1. Make sure you've updated your data
# Edit: src/data/portfolio.ts

# 2. Build for production
npm run build

# 3. Test the build locally
npm run preview

# 4. Deploy to GitHub Pages
npm run deploy
```

## Your Portfolio URL

```
https://chiragparashar24.github.io/portfolio-website/
```

## Development Commands

```bash
# Start dev server (http://localhost:3000)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Deploy to GitHub Pages
npm run deploy
```
