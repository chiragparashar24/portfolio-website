# Chirag Parashar — Portfolio Website

A modern, responsive, and recruiter-friendly portfolio website showcasing my work as an **AI/ML Developer** and **Full-Stack Engineer**.  
Designed to highlight my skills, projects, academic performance, and professional experience with a clean UI and smooth interactions.

---

## 🚀 Features

- Fully responsive design (desktop, tablet, mobile)
- Modern UI with smooth animations and hover effects
- Sticky navigation with smooth scrolling
- Resume download via popup modal
- Live contact form with success popup (no page redirect)
- Form auto-clear after successful submission
- SEO-friendly semantic HTML structure
- Fast loading (no heavy frameworks)

---

## 🛠️ Technologies Used

- **HTML5** — Semantic and accessible structure  
- **CSS3** — Modern layout, animations, responsiveness  
- **JavaScript (Vanilla)** — Interactivity, modals, form handling  
- **Web3Forms** — Contact form backend  
- **GitHub Pages** — Hosting & deployment
